# ⑤ 週次報告（設定曜日・時刻に送信）（★MVP）

毎日チェックし、`TRACE_Settings` の曜日に一致した日だけ週次サマリーをマネージャーへ Teams 送信。
**フロー改修なしで曜日・ON/OFFを変更できる**のが要点（既定：火曜・有効）。

- 種類：定期（Recurrence）
- コネクタ：SharePoint, Teams

## 手順

### 1. トリガー：繰り返し（Recurrence）
- 間隔：1 日 / タイムゾーン：Tokyo / 時刻：13:00（＝送信したい時刻。時刻はここで決める）

### 2. 設定を取得：項目の取得（SharePoint）
- リスト名：`TRACE_Settings`
- フィルター クエリ：`Title eq 'WeeklyReportDay' or Title eq 'WeeklyReportEnabled' or Title eq 'ManagerEmails'`
- 値の取り出し（式・1個ずつ「作成(Compose)」に入れると後が楽）：
  ```
  曜日   : first(filter(outputs('項目の取得')?['body/value'], x => x['Title'] == 'WeeklyReportDay'))?['SettingValue']
  有効   : first(filter(outputs('項目の取得')?['body/value'], x => x['Title'] == 'WeeklyReportEnabled'))?['SettingValue']
  宛先   : first(filter(outputs('項目の取得')?['body/value'], x => x['Title'] == 'ManagerEmails'))?['SettingValue']
  ```

### 3. 条件（Condition）：今日が設定曜日 かつ 有効
- 左辺（今日の英語曜日・日本時間）：
  ```
  formatDateTime(convertTimeZone(utcNow(),'UTC','Tokyo Standard Time'),'dddd')
  ```
  これが **設定の曜日（例 Tuesday）** と等しい（`is equal to`）
- かつ：`有効` が `true`（AND条件を追加）

> 設定値は `Tuesday` のような**英語の曜日**で持つ（CSV既定がそれ）。`dddd` は英語曜日を返す。

### 4.「はいの場合」→ サマリー集計 → Teams 送信
- 集計は **③マネージャー通知の手順3** と同じ OData フィルター件数を流用してよい
  （赤・黄・担当者なし＋今週の訪問件数など）
- 今週の訪問件数（例）：項目の取得 `TRACE_VisitHistory`
  ```
  VisitDate ge '@{addDays(utcNow(),-7,'yyyy-MM-ddTHH:mm:ssZ')}'
  ```
  → `length(...)`
- **チャットまたはチャネルでメッセージを投稿（Teams）**：Recipient=`宛先`、本文に上記件数を整形して記載

## 注意
- 時刻はトリガーの時刻で決まる（設定の `WeeklyReportTime` は表示用）。
  時刻も設定で動かしたい場合は、トリガーを毎時にして「現在時刻 == 設定時刻」を条件に足す（やや複雑・後回し推奨）。
