# ④ 営業向け朝の通知（毎朝8:30）（★MVP）

毎朝、各担当者に「本日フォロー予定の相手」を Teams で個別通知する。

- 種類：定期（Recurrence）
- コネクタ：SharePoint, Teams

## 手順

### 1. トリガー：繰り返し（Recurrence）
- 間隔：1 日 / タイムゾーン：Tokyo / 時刻：8:30

### 2. 本日フォロー予定を取得：項目の取得（SharePoint）
- リスト名：`TRACE_Customers`
- フィルター クエリ（次回フォロー日が今日以前・案件対応中/休眠/NG除外）：
  ```
  Status eq '通常' and IsHandling eq 0 and NextFollowDate ne null and NextFollowDate le '@{formatDateTime(convertTimeZone(utcNow(),'UTC','Tokyo Standard Time'),'yyyy-MM-ddT23:59:59')}'
  ```

### 3. 各担当者へ通知：Apply to each（手順2の value）
中に **条件**：`empty(item()?['AssignedTo'])` が **false**（担当者がいる人だけ）
→ はいの場合 → **チャットまたはチャネルでメッセージを投稿（Teams）**
- 投稿者：フロー ボット
- Recipient（宛先）：
  ```
  item()?['AssignedTo']?['Email']
  ```
- メッセージ（例）：
  ```
  おはようございます。本日フォロー予定：@{item()?['Title']}（@{item()?['ContactName']}）
  次回フォロー日：@{formatDateTime(item()?['NextFollowDate'],'yyyy/MM/dd')}
  ```

## 改良版（任意・通知を1人1通にまとめる）
件数が増えて「1人に何通も飛ぶ」のが気になったら：
1. 手順2の後に「アレイの作成」ではなく **担当者Emailで集約**：
   - `Select` で `{ email: AssignedTo/Email, name: Title }` に整形
   - `union()` や `Filter array` で担当者ごとにまとめ、1通に複数件を箇条書きで載せる
2. まずはMVPの「1件1通」で十分。賑やかさよりも確実さを優先。

## 注意
- `AssignedTo/Email` は担当者が**実在ユーザー**のときだけ入る。デモで未割当が多いと通知は飛ばない（正しい挙動）。
