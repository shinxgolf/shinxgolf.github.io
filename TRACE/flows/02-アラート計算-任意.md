# ② 毎日アラート計算（任意・将来の委任対策）

`DaysSinceContact`（数値）と `AlertStatus`（正常/黄/赤）を毎朝バッチで再計算し列に保存する。

- 種類：定期（Recurrence・毎朝7:00 Tokyo）
- コネクタ：SharePoint

## いつ必要？
- **MVP（全リスト2000件未満）では不要**。アプリ内の `DateDiff` で十分（委任警告は無視してOK）。
- 将来 1000件超になったら、数値列でのフィルタに切り替えるためにこのフローを導入する。

## 手順（概要）
1. トリガー：繰り返し（毎朝7:00 / Tokyo）
2. 項目の取得：`TRACE_Customers`（Status eq '通常'）
3. Apply to each →
   - `DaysSinceContact` =
     ```
     div(sub(ticks(utcNow()), ticks(item()?['LastContactDate'])), 864000000000)
     ```
   - `AlertStatus` = 条件で 365以上→赤 / 180以上→黄 / それ以外→正常
   - 「項目の更新」で2列を保存
4. `TRACE_Intermediaries` も同様（赤なし・60で黄）

## 切替後のアプリ側
- ギャラリーの Items を `Filter(..., DaysSinceContact >= varCustYellow)` のような**数値比較**に変更（委任可能）。
