# ③ マネージャー通知（毎朝8:00）（★MVP）

毎朝、アラート対象（黄・赤）と「担当者なし」の件数を集計し、マネージャーへ Teams 送信。
水曜会議の前に状況把握できるのが狙い。

- 種類：定期（Recurrence）
- コネクタ：SharePoint, Teams

## 手順

### 1. トリガー：繰り返し（Recurrence）
- 間隔：1 日
- タイムゾーン：(UTC+09:00) Osaka, Sapporo, Tokyo
- 設定時刻：8:00

### 2. 宛先を設定リストから取得：項目の取得（SharePoint）
- リスト名：`TRACE_Settings`
- フィルター クエリ：`Title eq 'ManagerEmails'`
- この後で使う宛先（式）：
  ```
  first(body('項目の取得')?['value'])?['SettingValue']
  ```
  ※アクション名が日本語と英語で変わる。自分のアクション名に合わせる（例：`outputs('項目の取得')?['body/value']`）。

### 3. 件数を OData フィルターで取得（日付はサーバー側で絞る＝委任回避）
「項目の取得」を必要数だけ並べる。各 **フィルター クエリ** に下記を貼る。
日付の境界はあらかじめ式で作る（日本時間基準）。閾値は既定値（黄180/赤365/仲介60）。

**黄：既存顧客（180日以上365日未満・案件対応中/休眠/NG除外）**
```
Status eq '通常' and IsHandling eq 0 and LastContactDate lt '@{addDays(utcNow(),-180,'yyyy-MM-ddTHH:mm:ssZ')}' and LastContactDate ge '@{addDays(utcNow(),-365,'yyyy-MM-ddTHH:mm:ssZ')}'
```
**赤：既存顧客（365日以上）**
```
Status eq '通常' and IsHandling eq 0 and LastContactDate lt '@{addDays(utcNow(),-365,'yyyy-MM-ddTHH:mm:ssZ')}'
```
**黄：仲介業者（60日以上）**
```
Status eq '通常' and LastContactDate lt '@{addDays(utcNow(),-60,'yyyy-MM-ddTHH:mm:ssZ')}'
```
**担当者なし：顧客**
```
Status eq '通常' and AssignedToId eq null
```
**担当者なし：仲介**
```
Status eq '通常' and AssignedToId eq null
```
> 各取得の件数は `length(outputs('そのアクション')?['body/value'])` で数える。
> `AssignedToId eq null` が効かない場合は、Status だけで取得 →「アレイのフィルター」で
> `empty(item()?['AssignedTo'])` を条件にし、その `length(body('アレイのフィルター'))` を使う。

### 4. Teams 送信：チャットまたはチャネルでメッセージを投稿（Teams）
- 投稿者：フロー ボット
- 投稿先：Chat with Flow bot（または Group chat）
- Recipient：手順2で取得した `ManagerEmails`（カンマ区切りなら `split(...)` で複数可）
- メッセージ（例）：
  ```
  【TRACE 朝の状況】@{formatDateTime(convertTimeZone(utcNow(),'UTC','Tokyo Standard Time'),'M月d日(ddd)')}
  🔴 赤アラート：@{length(outputs('赤_顧客')?['body/value'])} 件
  🟡 黄アラート：@{add(length(outputs('黄_顧客')?['body/value']), length(outputs('黄_仲介')?['body/value']))} 件
  ⚠️ 担当者なし：@{add(length(outputs('未割当_顧客')?['body/value']), length(outputs('未割当_仲介')?['body/value']))} 件
  ```
  ※ `outputs('...')` の名前は自分の各「項目の取得」アクション名に合わせて変える。

## 注意
- 閾値を `TRACE_Settings` から動的に読みたい場合は、`addDays` の `-180` 等を
  `mul(-1,int(<設定値>))` で差し替える（まずは固定値で動かすのを推奨）。
