# ⑥ AI要約（アプリから呼ぶ）

訪問テキストを受け取り、要約と次回フォロー候補日を返す。アプリの記録保存時に呼ぶ（ビルドガイド §6）。

- 種類：PowerApps（V2）トリガー
- コネクタ：AI Builder または Copilot/GPT（**Week1で可否判定**）

## まずWeek1で判定（重要）
`TRACE-構築手順書.md` の「検証①」に従い、追加コストなしで AI 要約が使えるか確認。
- ◯ 使える → このフローを本実装
- × 使えない → **アプリ内スタブ**に切替（下の「フォールバック」）

## 手順（使える場合）
1. トリガー：**PowerApps (V2)** — 入力テキスト `visitText`（テキスト）を1つ追加
2. AI アクション：
   - AI Builder「テキストの要約を作成」 もしくは「GPT でプロンプトを実行」
   - プロンプト例：
     ```
     次の営業訪問メモを、社内共有用に2〜3文で要約してください。
     さらに、次回フォローまでの推奨日数（既定90日）を数値で1行返してください。
     メモ：@{triggerBody()?['visitText']}
     ```
3. 次回フォロー日（式）：
   ```
   addDays(utcNow(), 90, 'yyyy-MM-dd')
   ```
   （AIが日数を返せるなら、その数値を使って `addDays` する）
4. **PowerApps または Flow に応答**：
   - `summary`（テキスト）＝ 要約結果
   - `nextFollow`（テキスト）＝ 次回フォロー日

## アプリ側の受け取り
```powerappsfl
Set(varAI, TRACE_Summarize.Run(locRecText));
// varAI.summary, varAI.nextFollow を提案パネルに表示
```

## フォールバック（AI不可のとき・デモ用スタブ）
フローを作らず、アプリ内で固定値：
```powerappsfl
Set(varAI, { summary:"（要約スタブ）" & Left(locRecText, 40) & "…", nextFollow: DateAdd(Today(), 90) })
```
役員会では「本番は Azure OpenAI 連携で実現」と口頭補足（プロトタイプ同様）。
