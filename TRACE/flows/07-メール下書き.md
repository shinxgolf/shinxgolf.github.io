# ⑦ メール下書き

相手の趣味・履歴・人となりを踏まえたメール文面を生成し、Outlook の下書きに保存する。

- 種類：PowerApps（V2）トリガー
- コネクタ：Office 365 Outlook（**標準コネクタ**）／本文生成は Copilot/AI Builder

## まずWeek1で判定
`TRACE-構築手順書.md`「検証②」：Outlook で下書き保存ができるか。
- ◯ → 本実装（下書きまで自動作成）
- × → **フォールバック**：本文だけ返してアプリ画面でコピー表示

## 手順（使える場合）
1. トリガー：**PowerApps (V2)** — 入力：`toEmail`, `personName`, `hobby`, `lastTopic`（テキスト）
2. 本文生成（AI Builder/GPT・任意）プロンプト例：
   ```
   取引先 @{triggerBody()?['personName']} さん宛に、丁寧で温かいフォローメールを書いてください。
   趣味：@{triggerBody()?['hobby']} / 前回の話題：@{triggerBody()?['lastTopic']}
   を自然に1文だけ織り込み、本文は150〜200字程度で。
   ```
3. **下書きの作成（Outlook）**：
   - 宛先：`triggerBody()?['toEmail']`
   - 件名：`先日はありがとうございました`
   - 本文：手順2の生成結果（無ければ定型文）

## フォールバック（下書き不可）
- 「PowerApps または Flow に応答」で `body`（テキスト）だけ返す
- アプリ側でテキストエリアに表示し、「コピー」ボタン（`Copy()` 相当はないので表示→長押しコピー）で対応
- PC版では `Set(varMailBody, ...)` をラベルに出してコピー

## アプリ側
```powerappsfl
Set(varMail, TRACE_MailDraft.Run(varSel.Email, varSel.Title, varSel.Hobby, "前回の話題"));
// varMail.body を表示 or 下書き作成完了をNotify
```
