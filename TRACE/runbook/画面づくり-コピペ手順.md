# 画面づくり — コピペ手順書（迷わない版）

> 目的：Power Apps Studio で、**上から順に「作る → 貼る」だけ**で画面が完成するようにしたもの。
> 数式の正本は `PowerApps-詳細ビルドガイド.md`。本書はそれを**作業順に並べ替え**たチェックリスト。
> 完成形は `../prototype/index.html`（ブラウザで開いて見ながら進めると速い）。

使い方：各ステップの ☐ を潰しながら進む。コードブロックは**そのまま貼る**。
コントロール名（`galAlert` 等）は本書の名前に合わせると、後のコピペがそのまま効く。

---

## 事前

- ☐ `scripts/Deploy-TRACE.ps1` を実行済み（5リスト＋データが入っている）
- ☐ make.powerapps.com →「キャンバスアプリを新規作成」→ **電話レイアウト**
- ☐ 左メニュー「データ」→ SharePoint を追加し、5リストを接続
  `TRACE_Intermediaries` / `TRACE_Customers` / `TRACE_Cases` / `TRACE_VisitHistory` / `TRACE_Settings`
- ☐ 「設定 → 機能」で **Navigate in App.OnStart を OFF**（推奨）

## STEP 1. App.OnStart（テーマ・設定読込）

☐ ツリー左上の **App** を選び、`OnStart` に貼る：

```powerappsfl
// ===== テーマ色（プロトタイプと一致）=====
Set(gPrimary, ColorValue("#0F1923"));
Set(gSurface, ColorValue("#1A2535"));
Set(gSurface2, ColorValue("#212F42"));
Set(gAccent,  ColorValue("#00D4FF"));
Set(gWarning, ColorValue("#FFB800"));
Set(gDanger,  ColorValue("#FF4444"));
Set(gSuccess, ColorValue("#00CC88"));
Set(gText,    ColorValue("#F0F4F8"));
Set(gSub,     ColorValue("#8899AA"));

// ===== ログインユーザー =====
Set(varMe, User().Email);
Set(varMyName, User().FullName);

// ===== 設定リストから閾値を読み込み =====
Set(varBrokerYellow, Value(LookUp(TRACE_Settings, Title="BrokerAlertDays").SettingValue));
Set(varCustYellow,   Value(LookUp(TRACE_Settings, Title="CustomerAlertYellow").SettingValue));
Set(varCustRed,      Value(LookUp(TRACE_Settings, Title="CustomerAlertRed").SettingValue));

// ===== マネージャー判定 =====
Set(varIsManager, varMe in Split(LookUp(TRACE_Settings, Title="ManagerEmails").SettingValue, ",").Value);

// ===== 初期タブ =====
Set(varTab, "home");
```

☐ App を右クリック →「OnStart の実行」で初期化（毎回プレビュー前に効かせる）

## STEP 3. ボトムナビ（4ボタン）

各画面の下部に水平コンテナ `cntNav` を置く（最初に scrHome で作り、後で他画面にコピペ）。

☐ コンテナ `cntNav`：`Height=72`、`Fill`：
```powerappsfl
RGBA(20,30,42,.95)
```
☐ 中にボタン4つ（ホーム/仲介/顧客/検索）。各ボタンの `OnSelect`（例：ホーム）：
```powerappsfl
Set(varTab,"home"); Navigate(scrHome, ScreenTransition.None)
```
（仲介＝`Set(varTab,"brokers"); Navigate(scrBrokers)` …のように変える）

☐ 各ボタンの `Color`（選択中をアクセント色に）：
```powerappsfl
If(varTab="home", gAccent, gSub)
```
> できたら `cntNav` を選んで Ctrl+C → 各画面で Ctrl+V。後で「コンポーネント化」すると保守が楽。

## STEP 4. scrHome（CTA＋TODAY＋ALERT）

☐ CTA ボタン「＋ 訪問を記録する」`OnSelect`：
```powerappsfl
UpdateContext({locShowRecord:true, locRecType:"", locRecText:""})
```

☐ TODAY ギャラリー `galToday` の `Items`：
```powerappsfl
Filter(
  TRACE_Customers,
  Status.Value = "通常",
  IsHandling = false,
  !IsBlank(NextFollowDate),
  NextFollowDate <= Today()
)
```

☐ 既存顧客アラート ギャラリー `galAlertCust` の `Items`：
```powerappsfl
SortByColumns(
  Filter(TRACE_Customers, Status.Value = "通常", IsHandling = false,
    DateDiff(LastContactDate, Today(), Days) >= varCustYellow),
  "LastContactDate", Ascending
)
```

☐ 仲介業者アラート ギャラリー `galAlertBroker` の `Items`：
```powerappsfl
SortByColumns(
  Filter(TRACE_Intermediaries, Status.Value = "通常",
    DateDiff(LastContactDate, Today(), Days) >= varBrokerYellow),
  "LastContactDate", Ascending
)
```

☐ アラートカード左の細い四角形 `Fill`（経過日で色分け）：
```powerappsfl
With({d: DateDiff(ThisItem.LastContactDate, Today(), Days)},
  If(d >= varCustRed, gDanger, d >= varCustYellow, gWarning, gSuccess)
)
```

☐「担当者なし」チップ（カード内ラベル）`Visible`：
```powerappsfl
ThisItem.Status.Value="通常" && IsBlank(ThisItem.AssignedTo.Email)
```

☐ カードタップ `OnSelect`（顧客カードの例）：
```powerappsfl
Set(varSel, ThisItem); Set(varSelKind, "customer"); Set(varDetailTab,"prof");
Navigate(scrDetail)
```
（仲介カードは `Set(varSelKind,"broker")`）

## STEP 6. scrDetail（タブ・担当者・状態バッジ）

`varSel`（選択レコード）と `varSelKind`（"broker"/"customer"）を使う。

☐ 状態バッジ ラベル `Text`：
```powerappsfl
Switch(true,
  varSel.Status.Value="対応NG", "⚠️ 対応NG",
  varSel.Status.Value="休眠", "休眠",
  varSelKind="customer" && varSel.IsHandling, "案件対応中",
  With({d:DateDiff(varSel.LastContactDate,Today(),Days)},
    If(d>=varCustRed,"赤 "&d&"日", d>=varCustYellow,"黄 "&d&"日","正常"))
)
```

☐ 対応NG 警告ラベル `Visible`：
```powerappsfl
varSel.Status.Value="対応NG"
```
☐「訪問記録」「メール下書き」ボタンの `DisplayMode`：
```powerappsfl
If(varSel.Status.Value="対応NG", DisplayMode.Disabled, DisplayMode.Edit)
```

☐ 担当者表示 ラベル `Text`：
```powerappsfl
If(IsBlank(varSel.AssignedTo.Email), "担当者なし", varSel.AssignedTo.DisplayName)
```

☐「変更」用 People Picker コンボ `cmbAssignee` の `Items`：
```powerappsfl
Office365Users.SearchUser({searchTerm:cmbAssignee.SearchText})
```
☐ 確定ボタン `OnSelect`（担当者を Patch）：
```powerappsfl
Patch(
  If(varSelKind="broker", TRACE_Intermediaries, TRACE_Customers),
  varSel,
  { AssignedTo:
    { '@odata.type':"#Microsoft.Azure.Connectors.SharePoint.SPListExpandedUser",
      Claims: "i:0#.f|membership|" & cmbAssignee.Selected.Mail,
      DisplayName: cmbAssignee.Selected.DisplayName,
      Email: cmbAssignee.Selected.Mail } }
);
Set(varSel, LookUp(If(varSelKind="broker",TRACE_Intermediaries,TRACE_Customers), ID=varSel.ID));
Notify("担当を変更しました", NotificationType.Success)
```

☐「自分が引き取る」ボタン `Visible`：
```powerappsfl
IsBlank(varSel.AssignedTo.Email) && varSel.Status.Value="通常"
```
☐ その `OnSelect`：
```powerappsfl
Patch(
  If(varSelKind="broker", TRACE_Intermediaries, TRACE_Customers),
  varSel,
  { AssignedTo:
    { '@odata.type':"#Microsoft.Azure.Connectors.SharePoint.SPListExpandedUser",
      Claims: "i:0#.f|membership|" & varMe,
      DisplayName: varMyName, Email: varMe } }
);
Notify("あなたの担当になりました 🙌", NotificationType.Success);
Set(varSel, LookUp(If(varSelKind="broker",TRACE_Intermediaries,TRACE_Customers), ID=varSel.ID))
```

☐ タブ切替ボタン `OnSelect`：`Set(varDetailTab,"prof")`（案件/履歴も同様）
各タブのコンテナ `Visible`：`varDetailTab="prof"` など

☐ 履歴タブ ギャラリー `Items`：
```powerappsfl
SortByColumns(
  Filter(TRACE_VisitHistory,
    RelatedType.Value = If(varSelKind="broker","仲介業者","既存顧客"),
    RelatedId = varSel.ID),
  "VisitDate", Descending
)
```
☐ 案件タブ ギャラリー `Items`：
```powerappsfl
If(varSelKind="broker",
   Filter(TRACE_Cases, BrokerName = varSel.Title),
   Filter(TRACE_Cases, CustomerName = varSel.Title))
```

## STEP 7. 記録モーダル（scrHome 内オーバーレイ）

☐ オーバーレイ コンテナ `cntRecord` の `Visible`：
```powerappsfl
locShowRecord
```
☐ 種別4択ボタン `OnSelect`（例）：`UpdateContext({locRecType:"訪問アポ"})`
枠色：`If(locRecType="訪問アポ", gAccent, gSub)`

☐「記録して保存」`OnSelect`：
```powerappsfl
Patch(TRACE_VisitHistory, Defaults(TRACE_VisitHistory),
  { Title: varSel.Title,
    RelatedType: {Value: If(varSelKind="broker","仲介業者","既存顧客")},
    RelatedId: varSel.ID,
    RelatedName: If(varSelKind="broker", varSel.Title, varSel.Title),
    VisitDate: Now(),
    VisitType: {Value: locRecType},
    RawText: locRecText
  }
);
// 最終接触日も更新（フロー①があれば省略可）
Patch(If(varSelKind="broker",TRACE_Intermediaries,TRACE_Customers), varSel, {LastContactDate: Now()});
// AI要約（フロー⑥）。無ければ下のスタブに差し替え
Set(varAI, TRACE_Summarize.Run(locRecText));
UpdateContext({locShowRecord:false, locShowAI:true})
```
☐ AI不可のときは最後の `Set(varAI,...)` を：
```powerappsfl
Set(varAI, { summary:"（要約スタブ）" & Left(locRecText,40) & "…", nextFollow: DateAdd(Today(),90) })
```
☐ AI提案「次回フォロー日を適用」`OnSelect`：
```powerappsfl
Patch(TRACE_Customers, varSel, {NextFollowDate: varAI.nextFollow});
Notify("更新しました", NotificationType.Success)
```


```powerappsfl

  Patch(TRACE_Customers, ThisRecord,
    { AssignedTo:{'@odata.type':"#Microsoft.Azure.Connectors.SharePoint.SPListExpandedUser",
      Claims:"i:0#.f|membership|"&cmbTo.Selected.Mail,
      DisplayName:cmbTo.Selected.DisplayName, Email:cmbTo.Selected.Mail} })
);
Notify("一括移管しました", NotificationType.Success)
```
