# 自動化の進め方（やさしい説明）

このメモは「専門用語なしで、何がどこまで自動になるのか」を説明するものです。

## たとえ話

TRACEアプリを作るのは、料理に似ています。

1. **食材と調理台を用意する**（＝データ置き場：SharePoint）… **完全に自動化できる**
2. **レシピ通りに料理する**（＝画面づくり：Power Apps）… レシピはあるが、調理は手が要る
3. **タイマーやアラームをセットする**（＝自動通知：Power Automate）… 設定の取り込みは自動化できる

## なぜ「画面づくり」だけ完全自動が難しいの？

- 画面を自動で作る方法（コード化）は存在します。
- でも、その自動生成は **あなたの会社のアカウントで一度試して直す** 作業が必要です。
- 私（AI側）は**あなたの会社のアカウントに入れない**ので、ここで完成確認ができません。
- 確認せずに「完成品」を渡すと、壊れていて逆に時間がかかる恐れがあります。

→ だから「確実な所（食材・調理台）は完全自動」「画面は“迷わず作れる材料”を用意」という形にしています。
